# Repository instructions

## No CI

The owner requires: **NEVER USE CI** (2026-10-04).

- Do not create, enable, restore, dispatch, rerun, or otherwise use CI workflows or external CI services.
- Validate changes locally with the repository's documented checks. Report checks that could not be run without falling back to CI.
- Historical CI references and archived workflow files are reference material only; they do not authorize CI.
- This policy stays in effect unless the owner explicitly changes it.
